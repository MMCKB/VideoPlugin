## 快速开始

**前提**：ClassIsland 2.1 及以上版本。

1. **下载** —— 到 [Releases](https://github.com/MMCKB/VideoPlugin/releases) 下载最新的 `ClassIsland.VideoPlayer.cipx`。
2. **安装** —— 打开 ClassIsland →【应用设置】→【插件】→【从本地安装】，选择该 `.cipx`，然后重启 ClassIsland。
3. **准备 FFmpeg** —— 打开【应用设置】→【视频播放器】，点【一键下载】（约 80 MB，只需一次）；也可以手动指定已有的 `ffmpeg.exe`。
4. **添加组件** —— 打开【应用设置】→【组件】，把「视频播放器」拖到主界面任意一行，再在它的设置里选择视频文件。
